# UDP 远程终端
基于UDP协议实现的可靠远程终端，应用层实现停等ARQ机制保证传输可靠性。

## 功能特性
✅ 基础UDP通信 + 自定义应用层协议
✅ 停等ARQ可靠传输（超时重传、ACK确认、去重、保序）
✅ 支持非交互式命令执行（ls、dir、pwd、ipconfig等）
✅ 多客户端同时连接，按客户端ID隔离
✅ 心跳保活机制，自动清理超时离线客户端
✅ 支持Ctrl+C中断远程正在执行的命令
✅ 大输出自动分块传输，最大报文1472字节避免IP分片
✅ 跨平台支持Windows/Linux/macOS
✅ 自动识别系统编码，Windows下不会乱码
✅ 非法报文直接丢弃，不影响服务器运行

## 支持的命令
这个远程终端会把你输入的命令**直接在服务端执行**，然后返回输出。理论上服务端支持的**非交互式命令**都可以运行：

| 操作系统 | 常用命令 |
|---|---|
| **Windows** | `dir`、`cd`、`pwd`、`ipconfig`、`echo`、`tasklist`、`netstat`、`ping`、`type`、`mkdir`、`del`、`cls` |
| **Linux/macOS** | `ls`、`pwd`、`cd`、`ip addr`、`ifconfig`、`echo`、`ps`、`netstat`、`ping`、`cat`、`mkdir`、`rm`、`df`、`top`、`clear` |

### ⚠️ 注意事项
- `cd`命令只会影响服务端子进程的工作目录，不会修改服务端全局工作目录
- 不支持需要交互式输入的命令（如`vim`、`python`解释器、`sudo`、`rm -i`等）
- Windows上建议用`dir`而不是`ls`（`ls`不是Windows原生命令）

### 特殊控制功能
| 操作 | 说明 |
|---|---|
| `exit` | 输入`exit`退出客户端 |
| `Ctrl+C` | 强制中断服务端正在运行的命令 |
| `-` | 按退格键会正确处理，显示不会乱码 |

## 使用方法
### 启动服务端
```bash
python server.py [端口]
# 默认监听0.0.0.0:9999
# 例如：python server.py 10000  # 监听10000端口
```

### 启动客户端
```bash
python client.py [服务端IP] [服务端端口]
# 默认连接127.0.0.1:9999
# 例如：python client.py 192.168.1.100 9999  # 连接到远程服务器
```

## 协议格式
固定头部12字节，采用大端字节序：
| 字段       | 长度 | 说明                     |
|------------|------|--------------------------|
| 魔数       | 2B   | 固定为0x1234，校验非法包 |
| 报文类型   | 1B   | 0:数据 1:ACK 2:心跳 3:中断 |
| 序列号     | 1B   | 0-255循环，用于停等ARQ   |
| 客户端ID   | 4B   | 唯一标识每个客户端       |
| 数据长度   | 4B   | 后续数据部分长度         |
| 数据       | 可变 | 最大1460字节             |
