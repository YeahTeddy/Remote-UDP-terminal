# UDP 远程终端
基于UDP协议实现的可靠远程终端，应用层实现停等ARQ机制保证传输可靠性。

## 功能特性
✅ 基础UDP通信 + 自定义应用层协议
✅ 停等ARQ可靠传输（超时重传、ACK确认、去重、保序）
✅ 支持非交互式命令执行（ls、dir、pwd、ipconfig等）
✅ 多客户端同时连接，按客户端ID隔离
✅ 心跳保活机制，自动清理超时离线客户端
✅ 支持Ctrl+C中断远程正在执行的命令
✅ 大输出自动分块传输，最大报文1472字节避免IP分片
✅ 跨平台支持Windows/Linux/macOS

## 使用方法
### 启动服务端
```bash
python server.py [端口]
# 默认监听0.0.0.0:9999
```

### 启动客户端
```bash
python client.py [服务端IP] [服务端端口]
# 默认连接127.0.0.1:9999
```

### 客户端操作
- 输入任意命令，回车执行
- 输入`exit`退出客户端
- 按`Ctrl+C`中断远程正在执行的命令

## 协议格式
固定头部12字节，采用大端字节序：
| 字段       | 长度 | 说明                     |
|------------|------|--------------------------|
| 魔数       | 2B   | 固定为0x1234，校验非法包 |
| 报文类型   | 1B   | 0:数据 1:ACK 2:心跳 3:中断 |
| 序列号     | 1B   | 0-255循环，用于停等ARQ   |
| 客户端ID   | 4B   | 唯一标识每个客户端       |
| 数据长度   | 4B   | 后续数据部分长度         |
| 数据       | 可变 | 最大1460字节             |
